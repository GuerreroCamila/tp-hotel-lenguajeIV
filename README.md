# Hotel Mapp — React

Proyecto educativo de una web de hotel con React 17 y React Router DOM 5.1.0.

## Instalación

1. Abrí una terminal en esta carpeta.
2. Ejecutá `npm install`.
3. Ejecutá `npm start`.

## Funciones

- Navegación entre Inicio, Habitaciones, Nosotros, Reservas y Contacto.
- Cuatro habitaciones con precios ficticios en ARS.
- Formulario de reserva con cálculo de noches y total.
- Validación de fechas, capacidad y superposición con reservas guardadas en el mismo navegador.
- Las solicitudes se almacenan en `localStorage`.
- Formulario de contacto demostrativo; no envía mensajes reales.

## Importante

Este proyecto es una demostración de frontend. `localStorage` no sincroniza reservas entre diferentes navegadores o dispositivos y no reemplaza un backend real. Los datos de contacto y precios son ficticios. No hay pagos reales.
